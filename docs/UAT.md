# แผนทดสอบ UAT — ระบบบริหารแผนและงบประมาณ

## วัตถุประสงค์

ยืนยันว่า workflow หลักตั้งแต่สร้างข้อเสนอโครงการจนถึงรับรองผลและตรวจสอบ audit trail ทำงานตามสิทธิ์ `admin`, `user`, `executive`, `staff` ก่อนเปิดใช้จริง

## เงื่อนไขก่อนเริ่ม

1. รัน migration `202609040001`, `202609040002` และ `202609040003` ตามลำดับ
2. รัน `supabase/verify-operational.sql` และต้องพบ RPC 4 รายการ, view 2 รายการ, bucket `evidence`, trigger และ policy ครบ
3. มีบัญชีทดสอบอย่างน้อย 4 บัญชี แยกตามบทบาท และกำหนด scope อย่างน้อย 2 หน่วยงาน
4. ผู้ตรวจ `user` และผู้อนุมัติ `executive` ต้องอยู่ใน scope เดียวกับข้อมูลทดสอบ
5. ใช้ข้อมูลทดสอบเท่านั้น ห้ามใช้เอกสารที่มีข้อมูลส่วนบุคคลจริง

## ชุดทดสอบอัตโนมัติ

รันคำสั่งต่อไปนี้ก่อนทดสอบด้วยผู้ใช้

```bash
npm run typecheck
npm run lint
npm run test:uat
npm run build
```

ผลที่ยอมรับได้: ทุกคำสั่งจบด้วย exit code `0` และไม่มี error

## เกณฑ์ผ่าน

- Critical/High ผ่าน 100%: RLS, วงเงินไม่เกินอนุมัติ, workflow, private evidence, admin self-lockout
- กรณีอื่นผ่านอย่างน้อย 95% และไม่มี defect ที่ทำให้ข้อมูลสูญหายหรืออนุมัติผิดคน
- ยอดรวม dashboard ต้องตรงกับทะเบียนโครงการ/เบิกจ่าย/KPI ใน scope เดียวกัน
- ผู้แทนฝ่ายแผน ผู้แทนการเงิน ผู้แทนประกันคุณภาพ และผู้ดูแลระบบลงนามรับรอง
