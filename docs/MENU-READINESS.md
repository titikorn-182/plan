# สถานะเมนูก่อนทดสอบด้วย Admin

## สิ่งที่ปรับในรอบนี้

- เพิ่มปุ่ม “เมนูทั้งหมด” บนหน้าหลักและหน้าทำงาน เปิดรายชื่อเมนูเต็มได้ทั้งเดสก์ท็อปและมือถือ ใช้แป้นพิมพ์และปิดด้วย Esc ได้
- รวมการเลือกเมนูตามบทบาทไว้จุดเดียว บัญชี Admin เห็นครบ ส่วนบทบาทอื่นยังไม่เห็นเมนูจัดการระบบ ไม่ได้เปลี่ยนสิทธิ์ในฐานข้อมูล
- เพิ่มการแจ้งเตือนในรายการเมนูหลัก และชื่อสำหรับไอคอนบนจอขนาดกลาง
- แสดงปุ่มสร้างข้อเสนอโครงการแม้ยังไม่มีโครงการ รวมถึงปุ่มย้อนหน้าหากเปิดหน้ารายการที่ไม่มีข้อมูล
- แสดงสถานะระหว่างเปิดหน้า เพื่อให้ทราบว่าเมนูกำลังโหลดข้อมูล

## เมนูหลักที่เชื่อมกับหน้าระบบแล้ว

| เมนู | เส้นทาง |
| --- | --- |
| หน้าหลักฐาน | `/` |
| ภาพรวมผู้บริหาร | `/reports` |
| แผนและคำของบ | `/budget-requests` |
| โครงการและการดำเนินงาน | `/projects` |
| รายงานรายไตรมาส | `/reports/quarterly` |
| เบิกจ่ายงบประมาณ | `/disbursements` |
| KPI และคุณภาพ | `/kpi` |
| หลักฐานและเอกสาร | `/evidence` |
| Workflow อนุมัติ | `/approvals` |
| การแจ้งเตือน | `/notifications` |
| กำกับและตั้งค่าระบบ | `/admin` — เฉพาะ Admin |

การเปิดหน้าสำเร็จไม่ได้หมายความว่าปุ่มภายในหน้านั้นพัฒนาเสร็จทั้งหมด และการมองเห็นเมนูไม่ใช้แทนการตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์

## ความสามารถที่พัฒนาเพิ่มแล้ว

- **ปีงบประมาณ / ไตรมาส:** เลือกจากข้อมูลจริง จำรอบใน cookie แบบ HTTP-only และกรอง dashboard/ทะเบียนหลักตามรอบเดียวกัน
- **ตัวกรองขั้นสูงโครงการ:** ค้นหา เลือกหน่วยงาน สุขภาพ สถานะ ช่วงงบประมาณ และช่วงความก้าวหน้าแบบ server-side พร้อมคงค่าเมื่อเปลี่ยนหน้า
- **เบิกจ่าย:** ดาวน์โหลดแม่แบบ นำเข้า XLSX/CSV ตรวจชนิดข้อมูล โครงการ สิทธิ์ ไตรมาส และวงเงินก่อนยืนยัน จากนั้นบันทึกหลายรายการในคำสั่งเดียว และส่งออก XLSX ตามรอบ
- **คลังรายงาน:** สร้าง XLSX จากข้อมูลจริงและเปิดหน้าพิมพ์/บันทึก PDF สำหรับคำของบ โครงการ เบิกจ่าย และ KPI
- **กำหนดการรายงาน:** เพิ่ม พัก เปิดใช้ และลบกำหนดการที่บันทึกด้วย RLS ตามเจ้าของบัญชี; Admin ตรวจสอบได้

การส่งไฟล์ตามเวลาอัตโนมัติยังไม่เปิด เพราะต้องกำหนด Scheduled Runner และช่องทางส่งขององค์กรก่อน ระบบแสดงข้อความขอบเขตนี้ตรงหน้า ไม่ใช้ข้อมูลตัวอย่างแทนสถานะจริง

## ปุ่มที่ต้องคงการล็อกไว้

- ปุ่มบันทึกระหว่างส่งข้อมูล เพื่อไม่ให้บันทึกซ้ำ
- การแก้ไขโครงการ/รายงาน/KPI ที่เข้าสู่ขั้นอนุมัติหรือรับรองแล้ว จนกว่าจะถูกส่งกลับตาม workflow
- การอัปโหลดเมื่อยังไม่มีรายการที่จะผูกหลักฐาน
- การกระทำที่อยู่นอกสิทธิ์ของบัญชี แม้จะเปิดหน้าได้

## การตรวจสอบ

- เพิ่ม unit/render tests 17 กรณี ตรวจ Admin เห็นครบ บทบาทอื่นไม่เห็นเมนู Admin เส้นทางมีอยู่จริง เลือกเมนูปัจจุบันถูกต้อง และปุ่มสร้างโครงการยังอยู่เมื่อข้อมูลว่าง
- `npm run check` ผ่าน 134 กรณีของ Vitest และชุด Node contract tests 22 กรณี
- ตรวจผ่านเบราว์เซอร์ด้วยส่วนประกอบจริงในหน้าจำลองเฉพาะเครื่อง ไม่เชื่อม Supabase: เปิดเมนูครบ 11 รายการ ตัวเลือกรอบ ตัวกรองโครงการ หน้านำเข้า และฟอร์มกำหนดการบนเดสก์ท็อป/มือถือ
- เพิ่ม full-stack test ให้ Admin เปิดครบทุกเมนูด้วยบัญชีทดสอบใน Supabase local; ยังไม่ได้รันกรณีใหม่นี้ในรอบนี้ ต้องรันบนเครื่องที่มี Docker หรือ GitHub Actions หลัง Push
- เพิ่ม migration และทดสอบกับ PostgreSQL แบบฝังตัวแล้ว แต่ยังไม่ได้ apply ให้ Supabase จริง บันทึกข้อมูลทดสอบในระบบจริง หรือ Push/Deploy รอบนี้
